00 · Bootstrap

Start in three minutes

Install Pass, complete the one-time runtime check, and let the app connect its local hooks and CLI. Pass never needs to own your sessions: tmux remains the source of truth.

Install and launch

Open the notarized DMG, drag Pass to Applications, then launch it. Pass v0.1.9 supports Apple Silicon and Intel Macs running macOS 14 or later.

Complete onboarding

Confirm tmux and Git, detect your coding agents, choose menu-bar-only or Dock + menu bar, then install integrations. Existing Claude hooks are merged and backed up.

Summon the control panel

Use your chosen global shortcut—⌘⌘ or ⌥Space—then create a session, register an existing repository, or clone a GitHub repository.

$ git clone https://github.com/lightsoft-dev/pass.git && cd pass
$ make open

02 · Persistence model

tmux is the database

Pass creates or adopts ordinary pass-* tmux sessions. It derives cwd, repository, branch, worktree, activity, and agent identity live—so closing Pass never closes the work.

01 / CREATEStart or adopt

Create from Pass, clone GitHub, or discover an existing pass-* session.

02 / OBSERVERead live state

Hooks report attention while tmux and Git provide identity and activity.

03 / DECIDEReply safely

Bracketed paste sends replies; bare shell prompts reject chat injection.

04 / HAND OFFAttach anywhere

Use the embedded terminal or attach from another terminal.

session handoff
$ tmux list-sessions
pass-my-project: 1 windows
$ tmux attach -t pass-my-project
Worktrees stay legible. Linked worktree sessions group beneath their main repository and carry a ⧉ badge while retaining their branch and cwd.

03 · Embedded browser

See it. Then operate it.

Each session can keep a persistent WKWebView beside its terminal. The same page is visible to the person and controllable through passcli, creating a reviewable automation loop without arbitrary JavaScript execution.

⌘ BShow or hide browser
⌘ LFocus URL field
⌘ ⇧ BToggle browser full width
⌘ + ⌘ − ⌘ 0Zoom / reset
01 / OPENNavigate

Open HTTP(S), localhost shorthand, a bare port, or a local file.

02 / SNAPSHOTObserve

Receive a revision plus stable refs for interactive elements.

03 / ACTInteract

Click, fill, type, select, press, or scroll using current refs.

04 / VERIFYRead or capture

Read text/HTML, snapshot again, or inspect a viewport PNG.

agent browser loop
$ passcli browser open localhost:5173
$ passcli browser snapshot --json
{ "revision": 12, "elements": [{ "ref": "@e1", "role": "button", "name": "Save" }] }
$ passcli browser click '@e1' --revision 12
$ passcli browser screenshot --out /tmp/result.png
S

Stable actions

Supplying a snapshot revision makes Pass reject stale refs after navigation or DOM changes.

V

Visible state

Automation operates the same persistent page the user sees. Background open can load quietly.

L

Limited surface

Only http, https, and file are accepted. There is no raw JavaScript, selector, cookie, or credential command.

T

Private text

Values passed to fill, type, and select are never echoed in human-readable output.

04 · passcli

Complete command reference

passcli is the local control plane for the running Pass app. Onboarding links it at ~/.pass/bin/passcli, and Pass sessions receive $PASS_CLI automatically.

1

Binary

Prefer $PASS_CLI, then ~/.pass/bin/passcli, then PATH.

2

Session

--session wins, then $PASS_SESSION, then enclosing tmux.

3

Server

Use $PASS_PORT when set; otherwise connect to loopback port 49817.

Start with status. Most commands require Pass to be running. Check reachability before session selection or browser state.

05 · Extension system

Make Pass yours

Extensions live at ~/.pass/extensions/<id>. They contribute quick commands, event rules, scripts, notifications, session actions, URLs, and constrained Web UI windows. Installed or generated code stays disabled until reviewed.

M

Extension Market

Browse public listings or paste a Git repo. Pass checks repository limits and manifest identity, then keeps the copy disabled.

browse / install
>

Quick commands

Enabled commands appear as >command-id in ⌘P. Context may be global, session, or project.

apiVersion 1+
E

Event rules

Observe attention pending/resolved and session created/ended events, filter them, then run one declared effect.

observation only
W

Web UI windows

apiVersion 2 can open isolated local HTML windows with getSnapshot, on, runAction, and closeWindow.

strict CSP
AI

AI Extension Builder

Describe a workflow. Pass starts a visible local agent session, then shows every generated file, permission, validation result, and summary. Approval records the content fingerprint; a changed file disables the extension on reload.

Extensions are user-account code. Pass validates schema and path containment, but scripts run with the user’s account and must be reviewed before enablement.

06 · Experimental workflow

Executable feature documents

Feature contracts can live with code in .pass/features/*.json, connecting requirements, an implementation agent, preview commands, evidence, and human review in a commit-friendly document.

Experimental status. The implementation exists, but Feature Documents are disabled in standard builds while the workflow is stabilized.
01 / DEFINEWrite contract

Requirements, acceptance criteria, local command/URL, and test guide.

02 / DELEGATEImplement or verify

An agent records summary, files, checks, and lifecycle status.

03 / TRYStart preview

Run the explicit dev command, open its URL, and follow the guide.

04 / REVIEWReturn feedback

Record rework notes. Only a person can mark verified.

07 · Device and remote surfaces

Leave the desktop, keep control

Pass can place a physical device beside the terminal and has developer-preview clients for remote session control. The Mac remains authoritative for repositories, tmux, and agents.

A

Android pane

Mirror a device or emulator with basic pointer control over USB/Wi-Fi. Optional runtime: brew install scrcpy ffmpeg.

video + pointer
i

iPhone and iPad

Use native trusted-USB capture. Unlock, trust the Mac, and allow camera access. Mirroring is view-only.

native capture
M

Mobile remote

The Expo preview lists and creates sessions, sends messages, and answers decisions through an outbound-only gateway and relay.

developer preview
D

Steam Deck client

A controller-first SteamOS client supports discovery, creation, terminal input, messages, and permission answers.

developer client
Remote boundary. The desktop dials out over TLS; the local hook/CLI server is never exposed. Current shared-token pairing is development-only.

08 · Reference

Diagnose by boundary

Most failures belong to one of four boundaries: app reachability, session targeting, browser state, or extension validity. Check them in that order.

SymptomCheckResolution
CLI unreachableStatus exits 3.Launch Pass, confirm PASS_PORT, and verify 127.0.0.1:49817.
No sessionNo explicit, environment, or tmux target.Use browser tabs, then supply --session.
Stale refPage changed after snapshot.Snapshot again and use only the new revision.
No open pageObservation/action precedes open.Open a URL for the same session first.
CLI/app mismatchLinked CLI is from another build.Rebuild or relaunch so the symlink points into the current bundle.
Extension disabledValidation failed or reviewed file changed.Validate, review all files/permissions, and approve the fingerprint.
